# Security

Switchgear does not ask for passwords or copy Codex authentication files. A profile's `CODEX_HOME` may contain credentials, sessions, and other sensitive state. Keep it outside repositories and synced/shared workspaces. Never attach its contents to an issue or commit them.

If you find a security problem, do not post credentials or a working exploit in a public issue. Contact the maintainer through the GitHub repository's private vulnerability reporting feature when available, or open a public issue containing only a non-sensitive description and ask for a private contact route.

Switchgear is not affiliated with or endorsed by OpenAI. It does not combine accounts, subscriptions, or usage limits.
